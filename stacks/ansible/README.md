# Ansible Stack

Deploys a K3s Kubernetes cluster on EC2 instances provisioned by the OpenTofu stack.

## Functionality

- Installs K3s server on the primary node
- Joins remaining nodes as K3s agents
- Configures cluster networking via Flannel CNI
- Uploads kubeconfig to S3 for downstream access

## Cluster Architecture

| Node | Role | Description |
|------|------|-------------|
| tofu-dev-1 | Server | K3s control plane, Kubernetes API |
| tofu-dev-2 | Agent | Worker node |
| tofu-dev-3 | Agent | Worker node |

**Networking**: Flannel CNI with VXLAN backend

## Security Groups

The deployment configures the following ports:

| Port | Protocol | Purpose |
|------|----------|---------|
| 22 | TCP | SSH access |
| 6443 | TCP | Kubernetes API server |
| 8472 | UDP | Flannel VXLAN |
| 10250 | TCP | Kubelet metrics |
| 30000-32767 | TCP | NodePort services |

## Kubeconfig Retrieval

After deployment, the kubeconfig is uploaded to S3:

```bash
aws s3 cp s3://<bucket>/kubeconfig-latest.yaml ~/.kube/config
kubectl get nodes
```

## Files

| File | Description |
|------|-------------|
| `playbook.yml` | Main Ansible playbook |
| `tofusible.yml` | Dynamic inventory configuration |
| `inventory_plugins/tofusible.py` | Inventory plugin for OpenTofu integration |

## Customization

Edit `playbook.yml` to modify:

- `k3s_version`: K3s release version
- `k3s_token`: Cluster join token (auto-generated by default)
- Additional K3s server/agent flags
